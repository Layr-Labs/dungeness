# History and Bézout representations

| Source | Retained reversible information |
|---|---|
| Schrottenloher | compact binary-Euclid branch transcript |
| Luo et al. | explicit remainders, coefficients, quotient fragments, lengths, and phase |
| Khattar et al. | explicit coefficients or an implicit Dialog transition sequence |
| Häner et al. | Kaliski state and fixed-round controls |
| measurement-based papers | classical outcomes plus a recomputable phase predicate |

## Conservation principle

Reversibility requires enough information to identify a path or reproduce its
action. It can move among:

```text
stored branch data
quotient digits
explicit coefficients
transition matrices
classical phase records
later recomputation
```

Deleting one representation is valid only after another representation is
shown to contain the required information.
