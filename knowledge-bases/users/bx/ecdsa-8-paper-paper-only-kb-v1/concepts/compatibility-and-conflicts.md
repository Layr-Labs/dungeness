# Compatibility and conflicts

## Natural combinations

- Luongo one-bit cleanup can wrap a comparator flag whose defining data
  remains available.
- Gidney carry venting can supply a constant-offset primitive inside a larger
  modular correction shell.
- Häner producer-consumer fusion can be applied around many arithmetic
  backends.
- Spooky scheduling can describe recomputation of any dependency graph whose
  checkpoint values satisfy the ghosting contract.

## Conditional combinations

- Luo full-register demolition needs an exact reconstruction of the deleted
  value.
- Litinski add-subtract needs its global correction identity.
- Khattar Dialog needs a new integer transition system before prime-field use.
- Montgomery arithmetic needs a complete representation boundary.

## Direct interface conflicts

```text
fresh-output multiplier vs in-place consumer
classical offset adder vs quantum addend
polynomial-field operation count vs integer prime-field cost
static reversal vs measured feed-forward circuit
approximate arithmetic vs exact worst-case claim
```
