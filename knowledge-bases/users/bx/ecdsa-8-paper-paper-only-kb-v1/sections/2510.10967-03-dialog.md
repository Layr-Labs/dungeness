# Khattar et al. — Dialog

Each EEA step emits a small invertible transition matrix. The sequence is the Dialog.

For the polynomial construction:

```text
fixed steps = 2n
len(poly) + len(dialog) = 2n
```

The evolving polynomial shrinks as the Dialog grows, so one shared register reaches the `2nb` leading-space minimum. Replaying the Dialog provides implicit coefficient access and direct division.
