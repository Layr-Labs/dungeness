# Paper 2607.13816 — Resource estimates and ECDLP integration

## Space

**[PAPER]**

```text
base inversion circuit:
  2n + 4 floor(log2 n) + 15

unary-iteration workspace:
  2 floor(log2 n) + 4

total inversion:
  2n + 6 floor(log2 n) + 19

point addition:
  3n + 6 floor(log2 n) + 19
```

At `n=256`, these are 579 and 835 qubits respectively.

## Gate costs by block

For active interval `[k_j(T),K_j(T)]`:

| Block | Toffoli coefficient | CNOT coefficient |
|---|---:|---:|
| `r`-side location-controlled add/sub | `11(K1-k1)` | `12(K1-k1)` |
| location-controlled swap | `2(K2-k2)` | `4(K2-k2)` |
| `t`-side location-controlled add/sub | `9(K3-k3)` | `10(K3-k3)` |
| `ell_t` update, only every fourth step | `24(K4-k4)` | `32(K4-k4)` |
| `ell_r'` update, only every fourth step | `24(K5-k5)` | `32(K5-k5)` |

Summing over the fixed schedule gives one forward inversion:

```text
Toffoli < 216.636 n^2 + O(n log n)
CNOT    < 273.795 n^2 + O(n log n)
```

The improved modular multiplication/squaring block costs:

```text
17n^2 + O(n log n) Toffolis
```

An affine point addition contains the equivalent of four inversions, six multiplication blocks, and two squarings at leading order:

```text
4*216.636 + 6*17 + 2*17 < 1003
```

so:

```text
point addition < 1003n^2 + O(n log n)
```

## Complete ECDLP

With signed windows:

```text
full Toffoli = 1008 n^3/log2 n + O(n^2)
```

At `n=256`, the paper uses `w=16` and 28 windows:

```text
28 * (5*2^16 + 70.10M)
≈ 2^30.88
```

The `2^30.63` sentence in Section 6.4 is arithmetically inconsistent and is treated as a typo.

## Architectural interpretation

**[SYNTHESIS]** The paper separates several space mechanisms that can be
studied independently:

- recycle a field register with measurement and phase repair;
- use liveness proofs to lower peak width;
- borrow inactive field bits as dirty workspace;
- use location-controlled arithmetic when logical values move within shared
  physical storage.
