# Paper 2607.13816 — Location-controlled circuit construction

The shared layout saves qubits by making value positions dynamic. Its price is that ordinary fixed-wire adders and swaps no longer suffice.

## Active windows

At algorithmic step `T`, the paper proves input-independent lower and upper bounds for each possible live location. A location-controlled circuit only spans:

```text
[k_j(T), K_j(T)]
```

rather than all `n+3` physical positions.

Separate windows are derived for:

- `r`-side add/subtract;
- the quotient-bit/location swap;
- `t`-side add/subtract;
- updating `ell_t`;
- updating `ell_r'`.

These windows are a static property of `T`, even though the actual boundary within the window remains in superposition. This distinction is useful for a compiler: step number narrows the physical candidate set; the quantum length value selects the actual location.

See [`luo-active-windows.md`](../nodes/luo-active-windows.md).

## Unary iteration

Given a length/index register promised to contain a value in `[k,K]`, unary iteration builds a selection tree for the corresponding indexed operation. Compared with running a full equality test independently for every possible index:

```text
selection Toffolis = O(K-k)
clean selection ancillas = O(log(K-k))
```

The temporary controls can be uncomputed as the tree is traversed. See [`luo-unary-iteration.md`](../nodes/luo-unary-iteration.md).

## Location-controlled primitives

### Swap

The quotient bit lies at a position selected by `ell_t+ell_q+1`. The swap circuit selects that wire and exchanges it with `Sign`.

Dominant paper cost:

```text
2(K-k) Toffolis
4(K-k) CNOTs
```

See [`luo-location-controlled-swap.md`](../nodes/luo-location-controlled-swap.md).

### Add/subtract

The arithmetic registers can be differently aligned and may cross the circular boundary in `Work2`. The explicit constructions combine unary selection with ripple-style majority/unmajority cells and phase controls.

Per active-window span, the paper reports:

```text
r side: 11(K-k) Toffolis, 12(K-k) CNOTs
t side:  9(K-k) Toffolis, 10(K-k) CNOTs
```

See [`luo-location-controlled-add-sub.md`](../nodes/luo-location-controlled-add-sub.md).

### Length update with dirty workspace

At an iteration boundary, the circuit must find the new bit length of a value whose endpoint lies in a known window. The paper borrows the inactive work bits in that window as dirty ancillas and restores them.

Per update:

```text
24(K-k) Toffolis
32(K-k) CNOTs
K-k+1 dirty borrowed bits
O(log(K-k)) clean unary-selection bits
```

See [`luo-dirty-length-update.md`](../nodes/luo-dirty-length-update.md).

## Representation lesson

**[SYNTHESIS]** The layout proof and the gate realization are separable:

- static liveness metadata for allocator reuse;
- step-specific truncation of comparison/addition spans;
- borrowing inactive high field bits as dirty scratch;
- replacing broad equality scans with one selected operation;
- proving when a qubit region is definitely zero or irrelevant.

The literal circuits minimize storage by paying for coherent selection and
boundary maintenance.
