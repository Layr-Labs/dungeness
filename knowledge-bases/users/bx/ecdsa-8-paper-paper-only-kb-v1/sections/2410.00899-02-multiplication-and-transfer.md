# Litinski — multiplication and transfer

## Constructions

**[PAPER]**

```text
full product: n^2 + 4n + 3
mod 2^n:     0.5n^2 + 1.5n
mod p:       n^2 + 6n + (n/w)(2^w + 3·2^(w/2) + 3n - 3)
```

The prime-modulus version uses Montgomery representation, windowed steps, lookup garbage, and final constant corrections.

## Interface conclusion

**[SYNTHESIS]** Treat this as a component library rather than an in-place
multiplier. The paper writes into a fresh accumulator, and its modular form
also changes the number representation.
