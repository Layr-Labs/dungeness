While the spooky pebble game can reduce the number of qubits needed to perform a compu-
tation, it is worth noting that it introduces new classical ancillary bits and does not reduce the
total memory (qubits plus classical bits). Nonetheless, qubits are a much more limited resource
than classical bits [13]. As such, we believe that this trade-off makes the spooky pebble game
pragmatic for designing algorithms that run on quantum computers.
