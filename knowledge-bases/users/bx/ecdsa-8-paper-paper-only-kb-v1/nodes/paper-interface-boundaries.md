# Paper interface boundaries

Resource claims are attached to complete interfaces. Before combining two
mechanisms, compare:

```text
input representation
output placement
classical versus quantum operands
control semantics
retained history or garbage
cleanup and phase repair
forward and inverse behavior
cost convention
```

Two constructions with the same mathematical function may have incompatible
register lifetimes or cleanup obligations.
