# Luo transfer boundaries

The low-space result depends on all of the following:

```text
four-phase exact EEA
shared moving-value layout
quantum length metadata
location-controlled arithmetic
full-register measurement and phase repair
```

The signed-window table-lookup wrapper is a separate layer. Resource claims
for the complete architecture should not be assigned to one isolated
mechanism.
