# Luongo transfer boundaries

The one-bit rule applies when a still-available state determines a Boolean
garbage function and a suitable self-adjoint repair computation exists.

Its saving is expected rather than worst-case. Measurement outcomes,
feed-forward, phase repair, and an explicit dynamic inverse are semantic
requirements.
