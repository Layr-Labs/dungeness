# Source: arXiv:2606.02235

## One-paragraph synthesis

**[PAPER]** The paper builds a low-space reversible affine point-addition circuit whose dominant operation is modular in-place multiplication. Its main architectural move is to split binary extended Euclid into two phases: first transform `(q, x)` into a compact record of branch decisions while freeing the input registers; then replay that record on a Bézout pair initialized as `(y, 0)`. By linearity, the replay performs multiplication by `x` or `x^-1` in place, depending on traversal direction. The paper combines this with register shrinking, a 3-iteration-to-5-bit history compressor, measurement-based uncomputation, truncated comparisons, and modular arithmetic specialized to the secp256k1 pseudo-Mersenne prime.

## Reported point-addition resources

The paper counts CCX, CCZ, and AND gates together as “Toffolis.” The figures below exclude the 16-qubit lookup window and its `3 * 2^16` lookup cost.

| Variant | Qubits | Toffolis | Notes |
|---|---:|---:|---|
| Paper, secp256k1, space optimized | 1192 | `2^21.19` | approximate, tested on 10,000 random inputs |
| Paper, secp256k1, gate optimized | 1446 | `2^20.83` | adds about `n` ancillas |
| Paper, generic prime, space optimized | 1192 | `2^21.78` | no pseudo-Mersenne shortcut |
| Paper, generic prime, gate optimized | 1446 | `2^21.42` | no pseudo-Mersenne shortcut |

**[CODE]** The companion repository was later updated. Its July 22, 2026 README reports approximately 1195 qubits / 2,304,135 Toffolis for the space version and 1443 qubits / 1,799,437 Toffolis for the gate version. Keep these later implementation figures separate from the paper-v1 claims.

## Central equations

Affine addition for distinct, non-opposite points:

```text
lambda = (y2 - y1) / (x2 - x1) mod p
x3     = lambda^2 - x1 - x2 mod p
y3     = lambda * (x1 - x3) - y1 mod p
```

In-place modular multiplication:

```text
|x, y> -> |x, x*y mod p>
```

Paper asymptotic space:

```text
history/tape            ~= 2.355 n + O(sqrt(n))
two live modular values  = 2 n
total                    ~= 4.355 n + O(sqrt(n))
```

Potential lower-space history encoding:

```text
information-theoretic history ~= 2.12 n + O(sqrt(n))
total lower target             ~= 4.12 n + O(sqrt(n))
```

## Fixed-step Euclid statistics

**[PAPER]** One loop iteration uses:

```text
b0 = v mod 2
b1 = (u > v)
record (b0, b0 & b1)
if b0 & b1: swap(u, v)
if b0:      v -= u
v >>= 1
```

The expected iteration count is derived as:

```text
L ~= 2n / log2(8/3) ~= 1.413 n
```

The observed standard deviation is about `0.6 sqrt(n)`. The paper chooses roughly four standard deviations of slack.

**[CODE]** For `n = 256`, the released implementation uses:

```text
ITERATIONS_VAR = 2.4
iterations = ceil((1.413*256 + 2.4*sqrt(256))/3)*3 = 402
U_PAD_VAR = 2.3
u/v padding = ceil(2.3*sqrt(256)) = 37 bits
history = (402/3)*5 = 670 bits
```

## Approximation parameters in companion code

```text
TRUNCATE      = 40  # Euclid comparison window, plus u/v padding
ITER_CAN_BE_Q = 50  # early replay steps use x+y=p-safe adder
PADDING       = 40  # replay modular add/double
PADDING2      = 50  # modular square-add
STEP          = 2   # rounds dynamic register widths for construction speed
```

These are empirical engineering parameters, not universal constants.

## Cost concentration

The paper's space-optimized secp256k1 breakdown:

| Component | Share of CCX |
|---|---:|
| In-place multiplier and inverse | 90% |
| Bézout reconstruction | 54% |
| GCD/history construction | 36% |
| Controlled modular adder and inverse | 39% |
| Hybrid adder | 22% |
| Controlled swap | 19% |
| Constant adders | 15% |
| Modular squaring | 9% |
| Modular double and inverse | 8% |

This makes the replay phase, controlled modular addition, swaps, and adders the primary optimization targets after the architecture is in place.

## Source limitations

- The paper accepts a small random-input failure probability; ecdsa.fail requires every tested shot to pass.
- The paper studies windowed addition by a selected built-in point; ecdsa.fail exposes a quantum target and a classical-bit offset point.
- The paper reports logical circuit resources; the benchmark's exact operation semantics and average executed-Toffoli metric differ.
- The companion implementation is Python/Qarton, while the benchmark implementation is Rust over a custom gate IR.
- The later companion-code revision is not identical to the arXiv v1 artifact.
