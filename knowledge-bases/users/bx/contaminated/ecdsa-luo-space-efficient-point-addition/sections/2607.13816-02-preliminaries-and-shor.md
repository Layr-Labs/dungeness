# Paper 2607.13816 — Preliminaries and Shor integration

## Cost model

**[PAPER]** The reversible arithmetic is specified primarily as Toffoli/CNOT/X networks. Toffoli gates are counted as the expensive non-Clifford proxy, while the explicit CNOT counts expose linear-reversible overhead. Measurements, resets, and classically controlled Pauli corrections appear in the point-addition layer.

This differs from ecdsa.fail in two important ways:

- the benchmark scores the average executed Toffoli count multiplied by peak allocated qubits;
- conditional branches and mid-circuit measurement can have harness-specific execution and inverse semantics.

Paper gate totals therefore cannot be used as benchmark scores without a concrete port and trusted evaluation.

## Elliptic-curve arithmetic

For affine points `P1=(x1,y1)` and `P2=(x2,y2)` with the usual nonexceptional assumptions:

```text
lambda = (y2-y1)/(x2-x1) mod p
x3     = lambda^2 - x1 - x2 mod p
y3     = lambda*(x1-x3) - y1 mod p
```

The paper's point-addition schedule is organized around one in-place division and one in-place multiplication, plus squaring and constant modular corrections. The denominator must be nonzero; exceptional cases are handled by the surrounding controlled schedule rather than by changing the inversion API.

## Shor's ECDLP circuit

The expensive coherent part of Shor's algorithm evaluates a double scalar multiplication. A semiclassical Fourier transform reduces the exponent-register footprint. Signed windows reduce the number of controlled point additions:

```text
window size w
approximately 2n/w point-addition windows
```

For the asymptotic bound, the paper chooses:

```text
w = 2 log2 n
```

One signed-window addition uses five sequential table lookups because the low-space point-addition core has only one free field register. At `n=256`, the concrete calculation uses:

```text
w = 16
28 signed-window additions
5*2^16 lookup Toffolis per window
```

The complete formula is:

```text
28 * (5*2^16 + Q_A)
```

where `Q_A=70.10M` is the controlled point-addition count. This evaluates to approximately `2^30.88`.

## What the benchmark does differently

**[BENCHMARK]** ecdsa.fail exposes:

```text
target_x, target_y: quantum field registers
offset_x, offset_y: runtime classical coordinate bits
```

The paper's lookup and signed-window wrapper assumes a point selected from a precomputed table. That wrapper is not the port target. The transferable layer begins below it:

- in-place division/multiplication dataflow;
- measured register recycling;
- liveness-driven register sharing;
- location-controlled arithmetic;
- clean/dirty ancillary allocation.

See [`luo-benchmark-adaptation.md`](../nodes/luo-benchmark-adaptation.md).
