## Concrete `n=256` layout

The code's shared layout agrees with the paper:

```text
T_max                 = 1620
small EEA state S     = 66 qubits
forward EEA width     = 2*256 + 66 = 578 qubits
controlled inversion  = 579 qubits
point-addition width  = 1 + 3*256 + 66 = 835 qubits
```

The leading `1` in the point-addition expression is the external control. The paper's closed form gives the same total:

```text
3n + 6 floor(log2 n) + 19 = 835
```

## Measurement implementation

**[CODE]** The Figure-15 builder explicitly emits:

- Hadamards over the old field register;
- measurements and resets;
- inverse EEA using the released register as workspace;
- recomputation of the measured value;
- classically conditioned Pauli-Z corrections;
- inverse recomputation;
- final register swap.

This code is useful for checking ordering and classical-control direction. It does not by itself establish compatibility with another circuit IR's measurement semantics.

## Point-addition implementation

The Figure-14 builder follows this high-level sequence:

```text
X -= x2
controlled: Y -= y2
IDiv(X, Y)
square-minus / x-coordinate updates
controlled constant corrections involving x2
IMul(X, Y)
controlled negation
X += x2
controlled: Y -= y2
```

The Qiskit resource builder treats selected point coordinates as classically precomputed constants. The ecdsa.fail offset coordinates are runtime classical bits, so the constant-arithmetic wrapper is not directly reusable.

## Counting pipeline

The full point-addition circuit is too large to flatten conveniently. The repository therefore:

1. decomposes reusable Qiskit blocks;
2. recursively counts operations in a target basis;
3. optionally optimizes bounded NCT segments;
4. assembles multiplication, inverse multiplication, in-place operations, and point addition with exact multiplicities.

Use these reports as resource accounting, not as a full quantum-state execution of the 256-bit circuit.

## Important implementation caveats

- Some `lowaux` helpers use serial equality scans and can be gate-heavier than the paper's ideal unary-iteration construction.
- Test harnesses imitate phase-sensitive or round-trip behavior, but they are not the ecdsa.fail trusted evaluator.
- Measurement/reset/feed-forward changes the inverse API. A caller must use the explicit inverse protocol rather than generic gate-list reversal.
- The resource code defaults to secp256k1 in several entry points, but the EEA itself is presented for generic odd prime fields.
