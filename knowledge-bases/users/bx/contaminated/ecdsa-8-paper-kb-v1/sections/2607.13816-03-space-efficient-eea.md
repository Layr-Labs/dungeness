# Paper 2607.13816 — Space-efficient extended Euclid

## Four-phase framework

The EEA maintains remainder values:

```text
r_(i-1) = q_i*r_i + r_(i+1)
```

and Bézout-coefficient values:

```text
t_(i+1) = t_(i-1) + q_i*t_i
```

The quotient is produced and consumed bit by bit using four phases:

1. shift `r_i` left to find the quotient's highest possible bit;
2. shift right while conditionally subtracting from `r_(i-1)` and writing quotient bits;
3. traverse quotient bits while adding shifted `t_i` into `t_(i-1)` and erasing the quotient;
4. shift the coefficient alignment back to its canonical position.

After phase 4, the two remainder roles and two coefficient roles swap for the next EEA iteration.

The phase and EEA-iteration reached at a given elementary step depend on `x`. The circuit therefore repeats one coherent step primitive for a uniform maximum number of steps rather than using a variable loop.

## Uniform step bound

**[PAPER]**

```text
4n <= required steps <= 4 ceil(c n)
c = 3/log2(2+sqrt(3))
```

The proof in Appendix A models quotient patterns using products of `2x2` matrices with a weighted cost. A finite polyhedral antinorm certifies a lower growth rate for every admissible product. This converts a fixed step budget into a guaranteed lower bound on remainder growth and therefore an upper bound on steps.

For `n=256`, the schedule length is `1620`.

## Shared physical storage

The invariant:

```text
r_(i-1)*t_i + r_i*t_(i-1) = p
```

implies that the remainder and coefficient magnitudes trade off. The construction uses:

```text
Work1 = t | q | r
Work2 = t' plus r'
```

with each work register `n+3` qubits. `Work2` may be circularly shifted, causing `t'` to wrap around its ends. Logical values are not separated by fixed physical partitions; their boundaries are encoded by four quantum length registers:

```text
ell_t, ell_q, ell_r', ell_s
```

## Optimized elementary step

The direct four-phase implementation repeats comparisons, shifts, and arithmetic at phase boundaries. Algorithm 3 merges equivalent operations under combined phase controls. One optimized step contains:

```text
pre-shifts
r-side location-controlled subtraction/addition
one merged location-controlled quotient-bit swap
t-side location-controlled subtraction/addition
post-shifts
phase transition logic
optional full Work1/Work2 swap and length refresh
```

The full work-register swap and length updates occur only at an EEA-iteration boundary:

```text
ell_q = 0 and ell_s = 0
```

See [`luo-optimized-eea-step.md`](../nodes/luo-optimized-eea-step.md).

## Forward inversion API

The EEA is deliberately not fully cleaned in its forward direction:

```text
|x>|0^n>|0^S>
  -> |x^-1>|0^n>|Gamma(x)>
```

Keeping `Gamma(x)` makes the forward circuit low-space. A later inverse EEA invocation clears `Gamma(x)` after another field register has been made available as workspace. This API is central to the measurement-assisted in-place division.

See [`luo-space-efficient-modular-inversion.md`](../nodes/luo-space-efficient-modular-inversion.md).
