# Spooky Pebbling — line frontier

If:

```text
n <= C(m+s-2, s-2) + 1
```

the line can be solved with `s` pebbles in `O(mn)` steps, and the paper proves a matching asymptotic lower bound.

Useful points:

```text
3 pebbles -> O(n^2)
O(log n) -> O(n log n)
O(n^epsilon) -> O(n/epsilon)
```
