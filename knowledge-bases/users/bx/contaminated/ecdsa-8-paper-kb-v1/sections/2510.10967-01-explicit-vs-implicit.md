# Khattar et al. — explicit versus implicit access

Explicit access stores the Bézout coefficients as ordinary field-element arrays. Implicit access stores the ordered transition sequence whose product acts as the Bézout transform.

The trade:

```text
explicit -> cheaper repeated reads, more direct state
implicit -> smaller/shared state, replay cost at each use
```
