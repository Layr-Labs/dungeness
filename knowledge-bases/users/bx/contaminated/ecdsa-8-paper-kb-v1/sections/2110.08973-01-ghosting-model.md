# Spooky Pebbling — ghosting

A pebble represents a coherent checkpoint. Ghosting measures and releases it but retains a classical phase obligation. Unghosting later recomputes the dependency state and applies adaptive phase correction.

This exchanges scarce qubits for:

```text
classical outcomes
recomputation
phase-correction work
```
