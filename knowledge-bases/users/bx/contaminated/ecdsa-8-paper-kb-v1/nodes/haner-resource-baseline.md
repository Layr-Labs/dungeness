# Häner resource baseline

**[PAPER]** For 256-bit ECDLP, the low-width configuration reports:

```text
2124 logical qubits
```

versus 2338 in RNSL, with factor-119 T-count and factor-54 T-depth improvements over that prior estimate.

These are full-algorithm Clifford+T metrics, not point-add benchmark metrics.
