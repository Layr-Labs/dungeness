# Source: arXiv:2510.10967

## Relevance to this KB

**[PAPER]** The paper's main application is Decoded Quantum Interferometry and Reed–Solomon decoding over binary extension fields. The relevant contribution here is a pair of reversible Extended Euclidean Algorithm architectures:

- synchronized EEA with explicit Bézout coefficients;
- a Dialog representation providing implicit access to Bézout coefficients.

## Explicit synchronized EEA

The circuit stores quotient information in the same shared registers as the evolving polynomial state instead of a separate quotient register. Localized swaps and a unified cycle produce:

```text
space: 2nb + O(log^2 n) qubits
worst-case schedule: approximately 6n iterations
leading work: 6n^2 quantum-quantum field multiplications
```

The `2nb` leading term equals the input size and is therefore space-optimal in that model.

## Dialog representation

The EEA is represented as a sequence of small invertible transition matrices:

```text
tau_1, tau_2, ..., tau_m
```

The full Bézout transform exists implicitly as their product. For the polynomial construction:

```text
fixed schedule = 2n steps
len(poly) + len(dialog) = 2n
```

As active remainders shrink by one field element, the Dialog grows by one, keeping the shared register at `2nb + O(log^2 n)`.

The Dialog can be replayed to perform direct modular multiplication or division without first materializing a separate inverse polynomial.

## Transfer boundary

The paper works mainly over `GF(2^b)`, where addition is XOR and multiplication/inversion have different costs from prime-field integer arithmetic. The current ping-pong sign tape also stores a branch bit that is not recoverable from the post-step value pair under the present recurrence. A prime-field Dialog port therefore requires a new transition system and an explicit recoverability proof.

## Source limitations

- DQI/RS resource totals do not measure secp256k1 arithmetic.
- Field multiplications are not interchangeable with prime-field integer additions.
- Implicit access can shift cost from storage into every later evaluation.
- The paper itself lists reducing the Dialog and transforming Dialogs directly as open questions.
