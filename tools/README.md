# Optional operator tools

`transcripts/` inspects retained local usage and transcripts. These tools are
not needed to execute or verify a run and are excluded from default runtime
bundles. See [distribution](../docs/runtime-distribution.md).

`antigravity-probe/` runs the official CLI against an offline synthetic provider
to check native Carbon integration assumptions. It is not a runtime provider;
see its [instructions and findings](antigravity-probe/README.md).
